# GridRP Screenshot Assets

Place your 1920x1080 (.webp or .png) gameplay screenshots in this directory with the following filenames:

1. `stock-exchange.webp` - Gang Stock Exchange candlestick charts and ticker
2. `turf-warfare.webp` - Flag poles and territory capture zones
3. `cyber-terminal.webp` - Personal computer terminal and L3 switch cabling
4. `money-printers.webp` - Bronze/Silver/Diamond printers and radial venting
5. `auction-house.webp` - Two-tier player auction house terminal
6. `corrections-jail.webp` - Multi-cell jail, Tasers, and forensics

The website automatically checks for these files and replaces the styled wireframe mockups with your actual screenshots.
